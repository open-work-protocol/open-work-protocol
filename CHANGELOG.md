# Changelog

## 0.2.0 — standards-readiness candidate

Breaking pre-1.0 changes:

- monetary amounts in normative work/contract/review objects are decimal strings rather than JSON floats;
- hashed-artifact canonicalization is explicitly constrained for cross-language determinism;
- extension data is namespaced under `extensions`;
- scope/non-overlap and optional profile boundaries are normative documentation;
- governance/IP/antitrust/trademark packets added;
- protocol positioning narrowed to outcome-work semantics rather than transport/marketplace ownership.

## 0.1.0 — experimental seed

Initial seven-object lifecycle, Git evidence profile, human gateway, A2A/x402/AP2/ERC-8004 composition profiles, TCK, and golden two-provider handoff journey.
