# RFC-0002 — Quality Routing

Status: Seed.

A global star average is weak and gameable.

A router should predict task-specific success using portable evidence. OWP standardizes evidence/decision boundaries, not one score.

The reference scorer uses Bayesian-smoothed history, domain fit, scale fit, handoff, reliability, security, and sample-size uncertainty. It is non-normative.

A routing event should record scorer identifier/version.
