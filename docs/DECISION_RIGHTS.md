# Decision Rights

OWP separates technical specification rights from commercial product rights.

## Specification maintainers decide

- core semantics;
- schemas and TCK;
- versioning/migrations;
- official reference profiles;
- security fixes to reference artifacts;
- conformance claim wording.

## Implementers independently decide

- whether to adopt OWP at all;
- which profiles to implement;
- models/agents/tools/orchestrator architecture;
- customer selection and risk rules;
- pricing, margins, fees, and payment providers;
- quality-routing algorithms;
- validation strictness above profile minimums;
- UI/brand/business model;
- whether to accept an individual work item.

## Repository owners decide

- access granted to providers;
- branch protection;
- review/merge/release authority;
- repository-local policy such as AGENTS.md/contribution rules.

No OWP governance vote can compel an independent implementation to adopt a feature or commercial policy.
