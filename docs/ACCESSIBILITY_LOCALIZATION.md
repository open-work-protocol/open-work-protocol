# Accessibility and Localization Requirements for OWP-Simple

The protocol does not own a consumer UI, but the Simple Flow profile exists specifically so nontechnical access is interoperable.

A production gateway SHOULD meet WCAG 2.2 AA or applicable local accessibility requirements, support keyboard/screen-reader operation, avoid color-only state, localize customer-visible strings/currency/date formatting, and preserve the original customer language alongside normalized machine objects.

Advanced audit data must remain available without being forced into the default flow.
