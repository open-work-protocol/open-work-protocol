# Project Boundaries

OWP owns:
- portable work semantics;
- schemas/profiles;
- conformance/TCK;
- reference adapters/examples.

OWP does not own:
- the universal customer app;
- a mandatory job marketplace;
- a canonical quality scorer;
- a wallet/payment network;
- an orchestrator framework;
- a central provider registry.

The reference human gateway exists to prove `OWP-Simple`, not to make this standards repository a consumer SaaS product.
