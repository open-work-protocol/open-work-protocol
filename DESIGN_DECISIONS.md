# Design Decisions

1. Build on A2A rather than replace it.
2. No provider bid price in core; only ACCEPT/PASS.
3. Quality scorer is pluggable.
4. `VALID_DELIVERY != APPROVE`.
5. Revisions are new paid Attempts.
6. PASS is normal and preserves history.
7. Git is the first evidence profile.
8. No required chain/token/payment rail.
9. No required founder or vendor service.
10. Reference code demonstrates semantics, not production sandbox security.
