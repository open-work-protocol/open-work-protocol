# Origin

Open Work Protocol was originally imagined by **Keeltrace** as a missing public layer for agent-orchestrated Git work.

That origin is attribution, not a dependency or control claim. OWP is designed so no founder, company, broker, model provider, payment rail, validator, registry, or hosted service is required for interoperability.

The intended lifecycle is simple:

```text
idea + Git-solvable outcome + posted budget
-> open WorkIntent
-> orchestrators ACCEPT/PASS
-> quality-routed provider
-> immutable paid Attempt
-> Git delivery + independent proof
-> approve / paid steer / paid reject
-> portable handoff when needed
-> finished product
```

**Imagined by Keeltrace. Built in Git. Meant to be implemented, forked, criticized, improved, and used by everyone.**
